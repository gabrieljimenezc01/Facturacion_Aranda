# Presentación y Compartir del Conocimiento

## Formatos de presentación

| Formato | Uso | Ejemplo |
|---------|-----|---------|
| **Manuales en PDF** | Documentación detallada | Manual de usuario (30 páginas) |
| **Infografías** | Pasos rápidos | "5 pasos para facturar" |
| **Guías rápidas** | Referencia de escritorio | Hoja laminada junto al computador |

## Estrategias para compartir conocimiento

### 1. Capacitaciones internas

**Frecuencia:** Semestral

**Modalidad:** Talleres prácticos

**Contenido:**
- Uso del sistema de facturación
- Atención al cliente

### 2. Inducción para nuevos funcionarios

**Duración:** 1 semana

**Método:** Acompañamiento con funcionario experimentado

**Materiales:**
- Manual de usuario
- Credenciales de acceso
- Enlaces a videos tutoriales

### 3. Comunicación diaria

| Canal | Uso |
|-------|-----|
| **WhatsApp** | Enlaces a documentos nuevos, avisos urgentes |

### 4. Reuniones de transferencia

**Frecuencia:** Mensual

**Participantes:** Todo el personal

**Objetivo:** Compartir lecciones aprendidas, buenas prácticas

## Política de actualización

| Documento | Responsable | Frecuencia de actualización |
|-----------|-------------|----------------------------|
| Manual de usuario | Secretario | Cada 6 meses o cambio mayor |
| Videos tutoriales | Secretario | Cuando cambie un proceso |
| Reglamento interno | Junta directiva | Anual o según necesidad |
| Formularios | Secretario | Inmediato si hay cambio |
