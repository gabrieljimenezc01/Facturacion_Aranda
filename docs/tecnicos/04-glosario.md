# Glosario de Términos - Acueducto Aranda

## Términos generales

| Término | Definición |
|---------|------------|
| **Administrador** | Usuario con permisos completos en el sistema. Puede crear, modificar y eliminar registros de clientes, facturas, lecturas, precios, entre otros. |
| **Cliente / Usuario** | Persona que recibe el servicio de agua. Está registrada en el sistema con información como nombre, dirección, medidor, estrato y sector. |
| **Factura** | Documento generado por el sistema que refleja el consumo de agua y el valor que el cliente debe pagar. |
| **Lectura del Medidor** | Registro del consumo de agua (en metros cúbicos) de un cliente, obtenido del medidor en un periodo específico. |
| **Sector** | Zona geográfica o barrio al que pertenece un cliente dentro del sistema de distribución de agua. |
| **Estrato Socioeconómico** | Clasificación económica del cliente, que puede influir en la tarifa que se le aplica. |
| **Fundador** | Cliente que participó en la creación o financiación inicial del sistema de acueducto. Tiene tarifas preferenciales. |
| **Abono** | Pago parcial que un cliente realiza para cubrir una deuda o factura pendiente. |
| **Acuerdo de Pago** | Compromiso registrado en el sistema en el cual un cliente acuerda pagar una deuda en uno o varios pagos. |
| **Listado de Tesorería** | Documento generado para que el tesorero registre y gestione los pagos realizados por los clientes. |
| **Listado del Secretario** | Registro utilizado por el secretario para confirmar el estado de pagos y realizar el cierre mensual. |
| **Tabla de Precios** | Representación de los rangos de consumo (m3) y sus respectivos valores, clasificados según el tipo de uso del agua. |
| **Sistema** | Aplicación informática que gestiona el registro, control y facturación del servicio de agua. |

## Roles del sistema

| Rol | Descripción |
|-----|-------------|
| **Administrador** | Usuario con máximos privilegios. Gestiona todo el sistema. |
| **Secretario** | Registra usuarios, ingresa lecturas, genera facturas, controla cartera. |
| **Tesorero** | Recauda pagos, administra efectivo, lleva registros financieros. |
| **Fontanero** | Toma lecturas de medidores, mantiene redes, opera planta de tratamiento. |

## Estados del servicio

| Estado | Descripción |
|--------|-------------|
| **Activo** | Usuario con servicio normal, al día en pagos. |
| **Suspendido** | Servicio temporalmente interrumpido por mora. |
| **Desconectado** | Servicio cancelado definitivamente. |

## Tipos de uso del agua

| Tipo | Descripción |
|------|-------------|
| **Residencial** | Viviendas particulares. |
| **Comercial** | Negocios, tiendas, pequeños comercios. |
| **Industrial** | Fábricas, industrias, alto consumo. |
