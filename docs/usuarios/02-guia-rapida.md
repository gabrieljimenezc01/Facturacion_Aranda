# Guía Rápida - Sistema de Facturación

## Acceso rápido

```
URL: http://localhost/Facturacion_Aranda/public/
```


## Tareas frecuentes (1 minuto o menos)

### ✅ Registrar cliente
`Usuarios → Registrar cliente → Llenar datos → Guardar`

### ✅ Generar facturas
`Facturación → Generar facturas → Seleccionar sector → Ingresar lecturas → Generar`

### ✅ Registrar pago
`Pagos → Registrar pago → Buscar cliente → Seleccionar factura → Confirmar`

### ✅ Ver deudores
`Reportes → Lista de deudores`

### ✅ Imprimir factura
`Facturación → Buscar facturas → Ver PDF → Ctrl+P`

## Atajos de teclado

| Tecla | Acción |
|-------|--------|
| Ctrl+B | Buscar cliente/factura |
| Ctrl+P | Imprimir desde vista PDF |
| Ctrl+G | Generar facturas |
| Esc | Cancelar operación actual |

## Estados de factura

| Estado | Significado |
|--------|-------------|
| Pagada | El cliente ya pagó |
| Pendiente | Aún no ha pagado |
| Vencida | Pasó la fecha límite |
| Anulada | Factura cancelada |
